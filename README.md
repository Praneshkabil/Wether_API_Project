# Weather API Project 

A beginner-friendly Python project that uses APIs to find the
weather of a location.

## How it works

1. User enters a place name.
2. Nominatim Geocoding API finds the latitude and longitude.
3. Open-Meteo API uses the coordinates to get weather data.
4. The program displays:
   - Location
   - Latitude
   - Longitude
   - Temperature
   - Wind Speed

## Technologies Used

- Python
- Requests
- Nominatim API
- Open-Meteo API
